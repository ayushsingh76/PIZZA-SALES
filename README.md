# PIZZA-SALES
This project focuses on analyzing pizza sales data using Microsoft Excel to uncover valuable business insights. The goal of this project is to understand sales performance, customer preferences, and revenue trends using Excel-based analytical techniques.

Project Objectives

Analyze overall sales performance

Identify best-selling and least-selling pizzas

Understand category-wise and size-wise sales distribution

Track revenue trends over time

Support business decision-making using data insights

🛠 Tools & Techniques Used

Microsoft Excel

Data Cleaning & Formatting

Pivot Tables

Pivot Charts

Sorting & Filtering

Basic Excel formulas

📊 Key Insights

Identified top-performing pizza categories and sizes

Analyzed daily and monthly sales trends

Determined revenue contribution by different pizza types

Highlighted customer demand patterns

📂 Dataset Information

The dataset contains pizza order details including order date, pizza type, category, size, quantity, and total price.

Data was cleaned and structured before analysis.

🎯 Learning Outcome

Improved hands-on experience with Excel for data analysis

Strengthened understanding of business-oriented analytics

Gained confidence in creating dashboards using Pivot Tables

🚀 Conclusion

This project demonstrates how Excel can be effectively used for beginner-to-intermediate level data analysis and can help businesses make data-driven decisions.
